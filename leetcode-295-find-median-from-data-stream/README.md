# 295 · Find Median from Data Stream

Run `npm start` from the repository root, then open `/leetcode-295-find-median-from-data-stream/`.

The animation preserves the supplied min-first insertion, partition transfer, and rebalancing order. The C# panel uses .NET 6 PriorityQueue and long negative priorities for the max-heap. Trees show logical binary heaps; .NET's internal queue layout differs.

Play, step, back, restart, change speed, or edit a stream of up to 16 Int32 values. A median query follows every insertion. Tests compare every result against a sorted-array oracle.
